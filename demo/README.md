# MPSMBD Video Walkthrough

This folder contains a short walkthrough of the MPSMBD database and its main research workflow.

## Watch the demo

[▶ Watch or download the MPSMBD walkthrough]

## What the demo shows

1. Exploring the database scale and five connected modules
2. Searching for a specialized metabolite
3. Reviewing metabolite information and associated pathways
4. Following ordered reaction steps in a biosynthetic pathway
5. Exploring known proteins and predicted candidate homologs
6. Reviewing the evidence associated with an individual candidate sequence
7. Using the guided Query Assistant
8. Exploring all the tools and applications

The walkthrough uses portfolio-approved interface content and does not include restricted source code, unpublished research data, or production credentials.
