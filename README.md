## Suggested video

Use `mpsmbd-walkthrough.mp4` for a 60–120 second walkthrough:

1. Select or search for a metabolite.
2. Open its associated biosynthetic pathways.
3. Identify a route that passes through the metabolite.
4. Compare predicted route completeness across species.
5. Inspect known and candidate enzymes for a required reaction step.
6. Show the supporting evidence attached to the selected reaction context.

## Before publishing

- Confirm that every visible record is approved for portfolio use.
- Remove internal hostnames, private URLs, user names, and browser bookmarks.
- Hide unpublished counts, sequences, raw evidence, and confidential labels.
- Confirm that screenshots do not reveal credentials, tokens, or environment settings.
- Use a demo or sanitized dataset where possible.
- Obtain permission for any third-party figure, logo, or copyrighted content.
- Review the final video frame by frame before uploading.

After adding approved media, replace the placeholder list in the root `README.md` with Markdown image links and a link to the hosted video or GitHub asset.
